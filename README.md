# School Vaccination Portal - React Frontend

This is the frontend web application for the School Vaccination Portal, built with React and TypeScript.

## 🛠 Tech Stack

- React + TypeScript
- Bootstrap CSS
- React Router
- Axios for API calls
- JWT Token-based auth

## 📁 Folder Structure

/src ├── /components -> Reusable UI components ├── /pages -> Dashboard, Students, Vaccination, Reports ├── /context -> Auth context ├── /services -> API handlers └── App.tsx -> Routes & layout


## 🚀 How to Run

### Prerequisites

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Steps

1. Clone the repository:

   git clone this repo.
   cd school-vaccine-portal

2. Install dependencies:   
   npm install

3. Start the development server:
   npm start
   
4. Open in browser:
   http://localhost:3000


### pages
	- Dashboard

	- Student Management

	- Vaccination Drives

	- Report Viewer with download options (CSV, Excel, PDF)
